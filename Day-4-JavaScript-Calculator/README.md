## 📖 Project Overview

This project is a **modern calculator application** developed using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations while providing a clean, responsive, and user-friendly interface.

The main objective of this project was to strengthen my understanding of JavaScript fundamentals by applying concepts in a real-world project.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 📱 Responsive Design
- 🎨 Modern UI
- 🖱 Interactive Buttons
- ❌ Clear (AC) Button
- ⌫ Delete Last Character
- ⚡ Instant Calculations
