# 🌐 Responsive Portfolio Homepage – Day 3

## 📌 Project Overview

This project was built as part of my **10-Day Full Stack Development Journey (Day 3)**.

The main objective was to create a **fully responsive portfolio homepage** that delivers a seamless user experience across mobile, tablet, and desktop devices using modern CSS techniques.

- 📏 Responsive Breakpoints
- 🖼️ Flexible Images
- 🌍 Viewport Units

- ⚡ Smooth User Experience
