# 🤖 AI Resume Analyzer (Day 10 - Full Stack Journey)

A lightweight web application designed to analyze resumes against job descriptions, calculate match percentages, and display keyword matches/gaps in real-time.

## ✨ Features

* **Interactive Text Inputs:** Paste custom Resume/CV content and Target Job Descriptions.
* **Smart ATS Scoring:** Dynamically calculates an overall ATS compatibility score based on technical keyword matching.
* **Keyword Matching System:**
  * **Matched Keywords:** Highlights technical skills present in both the resume and job description.
  * **Missing Keywords:** Lists missing target skills to help optimize the CV.
* **Responsive Modern UI:** Styled using Tailwind CSS and Font Awesome icons.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS
* **Core Logic:** Client-side parsing and match algorithms
* **Version Control:** Git & GitHub

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Click on **"Calculate ATS Score & Analyze"** to test!
