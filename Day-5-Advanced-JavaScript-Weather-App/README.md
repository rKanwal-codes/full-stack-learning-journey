# 🌦️ Day 5 – Advanced JavaScript Weather App

A responsive Weather App built using **HTML5, CSS3, and JavaScript** as part of my **10-Day Full Stack Development Journey**.

## 🚀 Project Overview

This project uses the **OpenWeather API** to fetch and display real-time weather information for any city. It helped me understand how JavaScript communicates with external APIs and handles asynchronous operations.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Display temperature
- 💧 Humidity information
- 🌬️ Wind speed
- ☁️ Weather condition
- 📱 Responsive design
- ⚡ Real-time API data
- ❌ Error handling for invalid cities

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Async / Await
- OpenWeather API

## 📚 Concepts Practiced

- ES6 Features
- Arrow Functions
- Fetch API
- Async / Await
- JSON Handling
- DOM Manipulation
- Event Handling
- API Integration
