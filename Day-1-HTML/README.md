# 📅 Day 1 — HTML Foundations

**10-Day Full Stack Journey | Building the Structure of the Web**

## 📖 Overview
Every great website starts with a strong foundation. Day 1 of this journey was focused on learning the building blocks of web development using HTML5 — the core skeleton that every modern website is built on.

## 🧠 Topics Covered
- HTML Document Structure
- Headings & Paragraphs
- Links & Images
- Lists & Tables
- Forms & User Input Elements
- Semantic HTML for accessibility

## 💻 Project: Personal Profile Website
A basic personal profile / portfolio webpage built using pure HTML to apply the concepts learned practically — including structure, headings, paragraphs, links, images, and a contact form.

### 🔧 How to Run
1. Clone this repository
2. Open the `day-1-html-foundations` folder
3. Open `index.html` in your browser

```bash
git clone https://github.com/rKanwal-codes/<your-repo-name>.git
cd day-1-html-foundations
```

## 🎯 Key Learnings
- Strong HTML foundations are essential for building scalable web applications.
- Clean structure improves readability and maintainability.
- Practical implementation helps transform concepts into real skills.
