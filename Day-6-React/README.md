# Day 6 — React: Student Dashboard

## 🚀 What I Built

A fully functional **Student Dashboard** built with React — my first real React project! It displays student profile info, course statistics, and a searchable, interactive list of courses.

## 🧠 Concepts Learned

- React project setup with Vite
- Components & JSX
- Props (parent → child data flow)
- State management with `useState`
- Event handling (`onClick`, `onChange`)
- Conditional rendering
- Rendering lists with `.map()`
- Filtering data with `.filter()`
- Component reusability

## 🛠️ Tech Stack

- React
- Vite
- CSS (custom, responsive design)
