# 🎨 Day 2 — CSS Fundamentals

**10-Day Full Stack Journey | Styling the Web with CSS**

## 📖 Overview
After building the structure of a webpage with HTML, Day 2 was focused on learning CSS3 to transform plain web pages into modern, attractive, and responsive websites. This included styling text, colors, layouts, spacing, Flexbox, and responsive design techniques.

## 🧠 Topics Covered
- CSS Introduction
- Inline, Internal & External CSS
- CSS Selectors
- Colors & Backgrounds
- Fonts & Text Styling
- Margin, Padding & Border
- Width & Height
- Display Property
- Position Property
- CSS Box Model
- Flexbox
- Responsive Design

## 💻 Project: Responsive Personal Portfolio

A modern and responsive personal portfolio website built using **HTML5** and **CSS3**. This project demonstrates clean layouts, Flexbox, modern UI styling, responsive design, and interactive hover effects.

### 🔧 How to Run
1. Clone this repository
2. Open the `Day-2-CSS` folder
3. Open `index.html` in your browser

```bash
git clone https://github.com/rKanwal-codes/full-stack-learning-journey.git
cd Day-2-CSS
```

## 🎯 Key Learnings
- Learned how to style web pages using CSS3.
- Understood the CSS Box Model for spacing and layout.
- Built responsive layouts using Flexbox.
- Applied colors, typography, and hover effects.
- Created a clean and modern user interface.
